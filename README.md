# HYS — Hiking Years & Stories

**HYS** 代表 **Hiking Years & Stories**。

每一次出發，都不只是完成一條路線，而是在歲月裡留下屬於自己的山林故事。這個專案用來整理登山紀錄、GPX 軌跡與沿途遇見的三角點，讓走過的路、看過的風景，以及每次登頂的回憶，都能被好好保存。
